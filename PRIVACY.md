# Privacy

termiHub collects no data about you: no telemetry, no analytics, no crash reporting service, no
account. Crash reports and logs stay on your computer. On its own, the app only asks GitHub
whether a newer termiHub exists (you can turn that off), and downloads an update, an agent binary
or the plugin index from GitHub when you ask for one. Every other connection goes to a server you
configured: SSH, telnet, FTP, RDP, VNC, remote agents and the network tools' targets.

The full privacy notice, with every connection, the data kept on your computer and how to delete
it, is in [docs/privacy.md](docs/privacy.md).
