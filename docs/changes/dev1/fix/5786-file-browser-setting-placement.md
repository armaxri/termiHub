### Changed

- **File browser setting moved to General** — the global File browser toggle (the SFTP browser
  default for SSH agent sessions) now sits under Settings › General › New connection defaults,
  next to X11 forwarding by default. It used to be the only entry under External files ›
  Advanced. Your saved value carries over, and searching "file browser", "sftp", "advanced" or
  "external" still finds it. External files now holds only the external connection file list.
