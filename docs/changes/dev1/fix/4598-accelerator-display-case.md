### Fixed

- Keyboard shortcuts: letter keys in displayed shortcuts are now always upper-case
  (`Cmd+B` instead of `Cmd+b`) in tooltips, the command palette, menus, the shortcuts
  overlay, the keyboard settings and the cheat sheet. Modifiers are listed with the
  platform's primary modifier first (`Cmd+Shift+T` on macOS, `Ctrl+Shift+T` on
  Windows/Linux). Saved custom shortcuts are unaffected.
