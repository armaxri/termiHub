### Fixed

- SSH tunnels now start on SSH connections created in the connection editor.
  Previously every such tunnel failed with "Failed to parse SSH config …
  invalid type: sequence, expected a map", because the tunnel read the saved
  connection with a stricter parser than terminal sessions use. The "Test
  connection path" probe had the same problem and is fixed too, and a `~` in
  a tunnel host's key path is now expanded.
- Anonymous FTP connections created in the editor now connect. Previously
  they failed with "Invalid FTP settings: invalid type: null".
- A terminal-less tab (FTP) whose connect fails now shows the real error
  message instead of "[object Object]".
- A new terminal's shell now always gets the terminal's real size. Previously
  a terminal that was already laid out before its session started could
  leave the shell at 80x24, so long lines wrapped and redrew wrongly until the
  window or panel was resized.
- After a GPU (WebGL) context loss, the terminal now re-fits itself when it
  falls back to the DOM renderer, instead of keeping a stale grid until the
  next resize.
