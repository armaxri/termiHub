### Added

- The keyboard-shortcuts overlay (<kbd>F1</kbd> / <kbd>Cmd</kbd>+<kbd>K</kbd>
  <kbd>Cmd</kbd>+<kbd>S</kbd>) now has an **Edit shortcuts…** button that opens
  **Settings → Keyboard Shortcuts**, so the read-only cheat sheet is no longer a
  dead end when you want to actually change a binding (UX-031).
- The shortcut recorder in **Settings → Keyboard Shortcuts** can now record
  **chord** sequences such as <kbd>Cmd</kbd>+<kbd>K</kbd> <kbd>Cmd</kbd>+<kbd>S</kbd>,
  not just single combinations. Press the first combination, then the second, and
  the chord is captured; the cell shows the captured combos live while recording.
  Single-combination recording is unchanged. This makes every chord the app ships
  and executes actually bindable through the UI (UX-032).
