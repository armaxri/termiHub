### Changed

- **Plainer Touch ID unlock note.** Settings ▸ Security no longer shows the
  "OS-enforced: no — …" paragraph under Unlock with Touch ID / Windows Hello.
  While the unlock is on, an app-protected key now reads "Less secure: other
  apps running as you could read the unlock key." with a warning icon, and an
  OS-enforced key reads a short "Protected by the operating system" note.
  Nothing shows while the unlock is off (#5752).
