### Added

- Services: a tunnel that does not start says which part failed and offers the remedy: "Edit
  connection" when the server refused the sign-in, "Review key" when its host key is not trusted,
  "Open a terminal on …" when the server did not answer, "Edit" when it did not allow the remote
  port (#6028).
- Services: a running tunnel whose target refuses says so, with when and how often (#6028).
- Services: a file server whose folder no longer exists says so, with "Choose folder", also on an
  agent (#6028).
- Services: Show path and Activity mark the part of a tunnel's path that fails; Open connections
  offers each service's next step and its Activity (#6028).
