### Added

- Services: the editor of a saved tunnel or file server has the sub-tabs Settings and Activity.
  Activity shows the state and since when, Start, Stop, Retry and Restart, the address with how to
  use it, connections now and in all, bytes sent and received, and what happened to the service
  since termiHub started (the last 200 changes) (#6028). A file server's requests are listed there too.

### Changed

- Services: Activity on a row opens the service's editor on Activity, for tunnels too. The access
  log of a file server no longer opens inside its row (#6028).
