### Added

- The command palette starts and stops each service; a stop says how many connections it cuts off
  (#6028).
- **Show services** and **Stop all services** can be given a shortcut in Settings (#6028).
- **Open connections** in the Services sidebar's "…" menu (#6028).

### Changed

- The status bar says how many services need attention: what failed, is not known, or waits for you
  (#6028).
- Open connections lists SSH tunnels and file servers in one **Services** section, with one Stop all
  (#6028).
