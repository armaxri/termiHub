### Added

- **Close panel shortcut** — `Cmd+Alt+W` (macOS) / `Alt+Shift+W` (Windows, Linux) closes the
  active split panel, asking first when it holds live sessions or unsaved files. The toolbar's
  Close panel tooltip names it.
- **Bindable session logging and macro playback** — "Toggle session logging" and "Play macro…"
  are now keyboard-shortcut actions (unbound by default) that you can bind in Settings ›
  Keyboard shortcuts and run from the command palette. Once bound, the terminal toolbar's "…"
  menu shows the shortcut.
