### Changed

- UI: the sidebars, their dialogs and the tools follow the new copy style guide
  (`docs/copy-style.md`). Titles, buttons, menu items and tooltips use sentence case
  ("New connection", "Keyboard shortcuts", "Export diagnostics…"), informational notices
  are dismissed with **Close**, and messages use US spelling ("canceled").
- UI: the SSH tunnel and workspace editors put **Cancel** on the left and the one primary
  action on the right ("Cancel · Save and start · Save"). The connection error dialog
  shows at most one primary action.
- UI: the DNS lookup panel's button that stops a running lookup now says **Stop**, like the
  other network tools.
- UI: deleting a saved HTTP monitor says **Delete monitor**, since it removes the saved
  monitor.
