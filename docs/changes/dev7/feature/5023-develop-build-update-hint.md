### Added

- Update checker: develop-branch dev builds now tell you when a newer develop build exists
  ("A newer develop build is available", with its build date and commit) and offer to open
  its download page. Notify only, nothing is downloaded or installed. Honours **Settings →
  Updates → Auto-check** and works with **Check Now**. Stable builds are unchanged; local
  development runs no longer check ([#5023](https://github.com/armaxri/termiHub/issues/5023)).
