### Fixed

- Remote desktop (VNC/RDP): keyboard and screen-reader users can now tell when the
  remote-desktop view holds the keyboard and how to get out of it. The view has an
  accessible name, shows a focus ring and a "Keyboard captured" hint while it has focus,
  announces capture and release to screen readers, and discloses the release chord
  (Ctrl+Alt+Shift; Ctrl+Option+Shift on macOS) in its description, the toolbar and the
  keyboard-shortcuts guide (#4328).
