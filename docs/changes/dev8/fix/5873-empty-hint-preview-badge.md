### Changed

- The empty Connections sidebar's experimental hint is now one short sentence ("Workflows are
  still experimental.") and a single "Turn on in Settings" button that opens Settings ▸ General.
  It used to spell out the settings path as one inline link that wrapped into several underlined
  pieces in a narrow sidebar (#5873).
- VNC and RDP in the connection type picker show a neutral "Preview" badge instead of the
  "— Experimental" suffix, and selecting one shows a one-line note that it is still being tested,
  with its known limits (VNC has no audio) (#5873).
