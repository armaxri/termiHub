### Fixed

- File browser: long file and folder names now end in "…" inside the list (the full name shows
  on hover) instead of being cut at the panel edge behind a horizontal scrollbar.
- File browser: Modified and Size are real, right-aligned columns under their headers. They hide
  together with their headers when the sidebar is too narrow or the listing has no such data, so
  a header never shows over an empty column.

### Added

- File browser: the header names whose filesystem you are browsing — "This computer" for the
  local disk, `user@host (SFTP)` for a remote one — with a distinct icon.
