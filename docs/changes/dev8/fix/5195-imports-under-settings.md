### Changed

- Imports now have one home: **Settings → Import & Migration** holds the
  `~/.ssh/config` import, CSV / inventory onboarding, JSON connection import and
  export, the MobaXterm import, and a link to Backup & Restore. The Connections
  sidebar header replaces its two import icons with a single
  **Import connections…** shortcut to that page, and the gear menu no longer
  lists Import Connections, Import from MobaXterm or Export Connections. The
  connection editor's `~/.ssh/config` button, which only fills in the form you
  are editing, is now labelled **Fill from ~/.ssh/config…** (#5195).
