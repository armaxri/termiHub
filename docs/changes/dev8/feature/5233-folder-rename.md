### Added

- Folders in the Connections tree and in a remote agent's tree can now be renamed.
  Choose **Rename** from the folder's context menu or press <kbd>F2</kbd> on the
  focused folder; the row turns into a text field where <kbd>Enter</kbd> saves and
  <kbd>Escape</kbd> cancels, and focus returns to the folder afterwards. Empty names and
  names already used next to the folder are refused with a message. The folder's
  connections, saved passwords and the open tabs and workspaces that use them follow the
  rename (#5233).
