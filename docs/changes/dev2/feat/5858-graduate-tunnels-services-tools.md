### Changed

- SSH tunnels, Services (embedded HTTP / FTP / TFTP servers) and Network tools are on by
  default. They no longer need **Settings ▸ General ▸ Allow experimental features**: the
  Activity Bar shows them, the file browser offers **Share via …**, and the status-bar
  services count opens the Services view. A view you hid from the Activity Bar stays hidden.
  The experimental switch now names what is still behind it: workflows, remote agents and
  RDP and VNC remote desktop (#5858).
