### Added

- Remote agents: connections saved on a remote agent can have an icon colour
  and/or an emoji icon too, set from the connection editor's Appearance tab.
  Both show on the agent's connection rows in the sidebar and on the tabs
  opened from them, and are stored on the agent (#5021). Needs an agent with
  protocol 0.33.0 or newer; for an older agent the controls stay hidden until
  it is updated.

### Changed

- Tabs opened from a connection saved on a remote agent now show that
  connection's custom icon (#5021).
