### Added

- Terminal settings now include a **Syntax Highlighting** section: a master
  on/off switch plus per-rule enable/disable of the built-in highlighting rules
  (error/warning/success keywords, URLs, file paths, IP addresses, numbers, and
  the opt-in P2/P3 rules), each shown with a color swatch and a live example.
  The section reads and writes the global `syntaxHighlighting` configuration, so
  changes take effect immediately in open terminals.
