### Changed

- Terminal dialogs, overlays, keyboard shortcut names and theme editor color names now use
  sentence case ("Rename tab", "Large paste", "View scrollback", "Toggle sidebar", "Bright
  red"). Closing a tab with unsaved edits and the close-window dialog's per-editor button now
  say **Discard changes** (formerly "Close anyway" and "Discard"). Canceled macro playback and
  workflow runs say "canceled" (#5391).
