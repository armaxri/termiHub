### Changed

- Context menu items now use sentence case: the tab menu ("Save to file", "Copy all", "Clear
  terminal", "Horizontal scrolling", "Set color…", "Close tab", "Move to new window"), the tab
  group chip menu ("Close group"), the log viewer ("Copy all logs") and the recent sessions menu
  ("Pin to top", "Remove from history"). The copy lint now checks menu item text, so new menu
  items follow the copy style guide too (#5491).
