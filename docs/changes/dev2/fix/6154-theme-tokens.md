### Changed

- The "update available", broadcast and running-automation colours are part of each theme now, with
  light-surface values in Light and Solarized Light, so they read on every surface. Custom and plugin
  themes can set them; older ones take the built-in values.
- Inputs, selects and text areas have a border that stands out from the input and the surface around
  it (3:1) in every theme, and the theme editor has an "Input border" colour.
- The keyboard focus ring is an outline drawn a little outside the control, so it shows on any
  surface.
- Disabled controls show muted text on a raised surface instead of being faded out.
- Light: the "connecting" dot is darker; Solarized Dark: raised surfaces are a touch darker, so
  secondary text on them reaches 4.5:1.
