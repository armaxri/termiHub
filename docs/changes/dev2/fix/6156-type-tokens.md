### Changed

- Section, group and column labels across sidebars, panels and dialogs share one look: small
  semibold secondary text in sentence case. The all-caps labels are gone, following the copy style.
- Headers, badges and row details use the 11px tier; the 10px tier is kept for the counts on the
  connection tree only.
- Empty sidebars all show the same compact empty state, the Files and Connections first-run
  messages included, and empty-state titles are medium weight everywhere.
