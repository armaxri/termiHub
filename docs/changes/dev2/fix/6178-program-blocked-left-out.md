### Fixed

- An automation that runs a local program while Settings ▸ Security ▸ "Allow automations to run
  local programs" is off now says on its row, in the Run picker, the palette, schedules and the
  editor that it will not run and which switch to turn on. A run is refused before anything is
  typed, instead of failing at that step.

### Changed

- What an import left out leads with a count and says where, for example "2 settings from a newer
  termiHub (“own”, “imported”) in step 2", in the import summary, on the row and in the editor.
