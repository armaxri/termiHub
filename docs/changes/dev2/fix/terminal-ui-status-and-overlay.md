### Accessibility

- Tab connection status is now shown with a distinct icon shape per state — a
  filled dot (connected), a spinner (connecting), a warning triangle (failed),
  and an unplugged icon (disconnected) — instead of a colour-only dot whose
  meaning was legible only on hover. Status is now distinguishable at a glance
  without relying on colour (WCAG 1.4.1 Use of Colour), with the per-state colour
  and the persistent accessible name kept as redundant cues (UX-014).
