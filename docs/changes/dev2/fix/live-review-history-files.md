### Changed

- Clearing the history of one automation offers "Clear this history" and "Clear all history", both
  shown as the irreversible actions they are; the wider one no longer looks like the safe choice.
- An import that meets a name already in your library says that it made a copy, and under which name.
- An automation whose step runs an automation that is not in your library keeps a mark on its row,
  with a way to choose one, until the step is fixed.
- The mark on a just-saved or just-run automation is an accent bar only, so it no longer looks like
  a second selected row.
