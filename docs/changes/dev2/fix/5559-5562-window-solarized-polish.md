### Changed

- The window toolbar now groups its actions into session, macro and layout
  groups with separators, and "Record macro" uses a record icon instead of a
  plain circle (#5559).
- The first section of the Connections sidebar is now called "Saved", so the
  sidebar no longer shows "Connections" twice (#5559).
- The status bar no longer shows the installed version; it shows an update chip
  only while an update is available. The version stays in Settings ▸ About
  (#5559).
- Settings confirm an auto-save with a "Saved" tick next to the setting you
  changed, instead of in the footer (#5562).
- Solarized Light highlights the selected connection with the palette's base2
  and a blue left bar, and its filled buttons use a slightly darker blue for
  more readable labels (#5562).

### Fixed

- Settings pages keep the same content width on every page and in every theme,
  whether or not the page scrolls (#5562).
