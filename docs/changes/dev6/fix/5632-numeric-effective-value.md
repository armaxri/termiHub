### Changed

- Settings: Font size, Line height and Scrollback buffer now show the value in effect as normal
  text instead of faint placeholder grey; line height reads "1.0". A small "Default" tag on the
  label row marks a setting that follows its default, and an overridden value gets an explicit
  "Reset to default" button, so every control spans the same width. Typing the default value back
  in returns the setting to the default. Settings hints are now upright instead of italic (#5632).
