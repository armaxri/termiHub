### Fixed

- Accessibility: screen readers now hear whether a file browser entry is a file, a folder
  or a symbolic link, whether it is selected, and how the list is sorted (for example
  "Name, sorted ascending"). The rows sit in a list named after the current folder.
- Accessibility: the tab-group chips in the workspace editor work from the keyboard. Tab
  reaches the active group, the arrow keys, Home and End move between groups, Enter or
  Space switches to the focused group, F2 (or Enter on the active group) renames it, and
  Delete removes it. A new Rename group button does the same as double-clicking a chip.
- Accessibility: in the Network Tools sidebar, a monitor's row can now be opened from the
  keyboard.
