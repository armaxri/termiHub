### Added

- File browser: **bookmarks**. The new Bookmarks button in the file browser toolbar bookmarks the
  current folder (or removes its bookmark) and jumps to any bookmarked folder; **Manage
  Bookmarks…** renames and removes them. Bookmarks are kept per connection — every local browser
  shares one list, a remote browser uses the saved connection's list — and survive restarts. They
  are included in backups as the new "File browser bookmarks" section. (#3558)
