### Added

- File browser: a **dual-pane transfer view**. Open it with the new columns button in the file
  browser toolbar. Your local disk is on the left and a remote connection (SSH, SFTP, FTP,
  Docker or agent session) is on the right. Copy files and whole folders between the panes with
  the arrow buttons, **F5**, or by dragging rows onto the other pane. termiHub asks before it
  replaces an existing item. Copies run through the Transfer Queue, and their progress, pause,
  cancel and retry controls appear below the panes. Both lists work fully from the keyboard.
  (#3558)
