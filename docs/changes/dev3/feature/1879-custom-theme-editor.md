### Added

- Appearance: custom color themes. A new **New Theme** action in Appearance
  settings opens a theme editor where you can name a theme, pick a built-in
  theme to base it on, and adjust every UI and terminal color (backgrounds,
  text, borders, status, all 16 ANSI colors, and more) with a swatch + hex
  field and per-color reset. Edits preview live across the whole app. Saved
  custom themes appear in the Theme dropdown alongside the built-in ones and can
  be selected, edited, or deleted; deleting the active theme falls back to Dark.
  Custom themes are persisted with your settings (#1879).
