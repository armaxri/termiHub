### Changed

- Settings: number settings such as font size, line height, scrollback and the
  session history limit are short boxes sized to their values, with a unit
  ("px", "lines", "sessions") beside them, instead of full-width fields (#5843).
- Settings: the "Default" marker beside a setting is plain grey text, so it no
  longer looks like a button. Once you change a value, a "Reset to default"
  button takes its place (#5843).
- Settings: long descriptions are one line, with the details (limits,
  retention, the default font list) behind a "?" beside the setting's name
  (#5843).
- Settings: "Clear all history" and "Clear network tool history" are normal
  buttons instead of red ones (#5843).
- Settings: the search bar, category list and settings sit in one centred
  column, so wide windows no longer leave the settings floating on the left
  (#5843).
