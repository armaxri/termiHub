### Fixed

- The macro, workflow, schedule, service, theme and highlight-rule editors no
  longer open with "Name is required." in red. Like the connection editor, they
  show a field's error only after you have changed the field and moved on, or
  when you try to save. Save is no longer greyed out beyond reach: clicking it
  while something is missing saves nothing, shows every problem at once and
  moves the cursor to the first one (#5917).
