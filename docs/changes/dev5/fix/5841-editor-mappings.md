### Changed

- Settings ▸ Editor: your own file type mappings and the form to add one come
  first. The built-in mappings are folded behind "Show built-in mappings (N)",
  with a filter to find a file or language once unfolded (#5841).
- Settings ▸ Editor: the language of a new mapping is picked from a searchable
  list of known languages instead of typed, so a typo can no longer save a
  language the editor does not know. Saved mappings with an unknown language
  are marked "unknown language". The page says "language" instead of "Monaco
  language ID" (#5841).
