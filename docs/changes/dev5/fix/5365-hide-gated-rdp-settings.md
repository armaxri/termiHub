### Changed

- Settings now hide RDP/VNC-only surfaces while experimental features are off,
  matching the hidden VNC/RDP connection types: the **Security → Remembered RDP
  Certificates** section (also absent from Settings search), the **Remote
  Desktop** group in Keyboard settings, the shortcuts overlay and the exported
  keyboard cheat sheet (#5403), and the RDP/VNC mention in the MobaXterm import
  description. Remembered certificates and any Remote Desktop shortcut overrides
  stay stored and reappear when experimental features are turned on (#5365).
