### Fixed

- Terminal command status marks (the bars shell integration draws beside each
  finished command) are wider and easier to see. A failed command's bar has a
  notch cut into it, so it no longer looks like a successful command's solid
  bar in a different shade.
- Hovering a command mark now works across the whole left margin of the
  prompt line and shows the exit code and how long the command ran, for
  example "Command failed · exit code 1 · took 2.3s".
