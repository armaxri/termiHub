### Changed

- Settings: the file manager page is now called "Open in termiHub", after the
  entry it adds to the right-click menu. Its status and button name your file
  manager the same way: "Not added to Finder" beside "Add to Finder" (File
  Explorer on Windows, "your file manager" on Linux), then "Update" and
  "Remove from Finder" once it is added (#5845).
- Settings: "Fallback when no entry matches" is now "When opening a folder",
  with the choices "Ask which session" and "Open a new terminal". The hint on
  how to reorder quick-access entries only shows once there are two (#5845).
- The one-time "Open in termiHub" offer shows "Add to Finder" as the main
  button right next to "Not now", and after "Not now" says where to find it
  later: Settings ▸ Open in termiHub (#5845).
