### Added

- VNC: **Files → Browse remote files** opens the File Browser on the session's SSH tunnel (SFTP)
  or agent host, at the upload folder, with the account, host and carrier shown at the top.
  Download a file there as usual: you choose the local folder and it runs in the Transfers queue
  with progress and cancel. **Upload to folder…** now lets you browse the host's folders, and the
  upload summary offers **Reveal** to open the browser at the destination. View-only sessions get
  no entry point (#4193, #4204, concept #3770).
