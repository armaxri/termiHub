### Changed

- The terminal toolbar above the tabs now shows only the layout icons: new terminal, split
  right, split down, close panel and the sidebar toggle. Each tooltip names its keyboard
  shortcut, which follows your platform and any shortcut you changed in Settings. Broadcast
  input, session logging, macro recording and macro playback moved into a "…" menu. Menu
  entries with a shortcut show it right-aligned (#5756).
- A running broadcast, recording, playback or session log shows as a labelled chip next to
  the toolbar icons ("Broadcasting", "Recording", "Playing 2/5", "Logging"). Click the chip
  to stop it (#5756).
