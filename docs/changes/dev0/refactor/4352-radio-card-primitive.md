### Changed

- Option-card choices (Settings → Updates auto-check, Settings → Security
  credential storage, the tunnel editor's Local/Remote/Dynamic type, and a jump
  host's Saved/Inline source) now share one card style and behave as proper
  radio groups: the group is a single Tab stop, arrow keys move and select, and
  screen readers announce the group name, each option and its description.
  Workflow trigger chips use the same accent selection style (#4352).
