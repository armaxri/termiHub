### Added

- Connections saved on a remote agent can have a short description too: one
  line of at most 80 characters, set in the connection editor. It shows muted
  under the name in the Remote Agents tree, and the search matches it. The
  field appears only for an agent that can store it (agent protocol 0.42.0 or
  newer); update an older agent to use it. Existing agent connection files
  load unchanged.
