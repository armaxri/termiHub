### Added

- The file browser can now download multiple selected files and folders at once:
  select several entries and choose "Download" from the multi-select context
  menu. Each entry downloads through the existing single-download path (a
  selected folder recurses the same way a single folder download does), showing
  the normal per-transfer feedback (PROD-005).
- A toolbar toggle to show or hide hidden (dot-prefixed) files in the file
  browser. Hidden files are hidden by default (the standard file-explorer
  default) and the toggle state persists across restarts (PROD-008).
