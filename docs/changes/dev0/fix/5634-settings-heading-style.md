### Changed

- Settings: every category now uses one section heading style — sentence case,
  the same size, weight and colour, with a thin divider underneath — instead of
  a small grey heading on some pages and a large white one on others. Plugin
  section headings no longer carry decorative icons (#5634).
- Settings: warning hints (such as Allow experimental features and the plugin
  trust warnings) now lead with a warning icon, so amber is never the only sign
  of a caution (#5634).
