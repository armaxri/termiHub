### Fixed

- File browser: refreshing while a folder is still loading no longer jumps back to
  the previous folder, so a newly connected SSH session's browser no longer gets
  stuck on `/` (#4017).
- File browser: switching to a session that reports no working directory (an
  SFTP-only or FTP host) now lists that session's home instead of keeping the
  previous session's folder, where browsing and uploads would act on the wrong
  path (#4017).
- File browser and transfer view: shell sessions on a remote agent can browse the
  agent host's files instead of showing "No filesystem available" (#4017).
- Spawning an SSH session from outside the app (`termihub spawn --kind ssh`) now
  asks for the password (or uses the stored one) before connecting, instead of
  failing authentication with an empty password (#4017).
- Terminal: an inline image (SIXEL / iTerm2) sent right after a session connects
  is no longer dropped while the image support is still loading (#4017).
