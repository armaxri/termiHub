### Fixed

- File browser: FTP and SFTP-only sessions now list the login directory when they
  open, instead of failing with "No such file or directory" on `~`; uploads then
  land in that directory rather than in a previous session's folder (#4017).
- Terminal: an inline SIXEL image sent right after a session connects (for example
  by a Telnet host) is no longer dropped while the image decoder is still starting
  (#4017).
