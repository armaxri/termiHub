### Added

- Connections sidebar: desktop-local saved connections whose type supports
  persistent (background) sessions now show the ∞ persistence badge and a
  run-state dot, and expose **Start**, **Attach New Tab**, and **Stop**
  controls as inline hover buttons and in the right-click context menu. The
  badge's tooltip clarifies that a desktop-local session runs only while the
  app is open — use a remote agent for across-session persistence (#1881).
