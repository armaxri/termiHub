### Added

- **Settings → Security → Imported Workspace Confirmations** lists the imported
  workspace commands and inline connections you have confirmed on this machine,
  grouped by the workspace that holds them. Confirmations no saved workspace uses
  any more show as "No longer used". Each one can be revoked on its own, or all
  at once with **Revoke All**, after a confirmation dialog. A revoked item waits
  for confirmation again the next time a workspace launches, and shows as
  unconfirmed in the workspace editor. Settings search finds the section by
  "allowlist", "imported" or "revoke" (#4445).
