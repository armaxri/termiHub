### Added

- F6 and Shift+F6 move keyboard focus between the activity bar, sidebar,
  terminal area and status bar, skipping hidden regions. A focused terminal
  keeps F6 / Shift+F6 for the program running in it. Use Ctrl+F6 /
  Ctrl+Shift+F6 (Cmd+F6 / Cmd+Shift+F6 on macOS) to cycle regions from inside a
  terminal. All four shortcuts can be rebound (#4773).
