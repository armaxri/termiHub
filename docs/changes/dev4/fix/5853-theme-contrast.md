### Changed

- Solarized Light: the activity bar is now light (base2) with dark icons, so it matches the
  cream sidebar and editor instead of drawing the eye to the icon column.

### Fixed

- Solarized Light and Solarized Dark: the selected row in the connection tree, file browser,
  plugin list and transfer panes now has a thin outline, so the selection is easy to spot.
- Light: hints and empty-state text in the sidebar are darker and easier to read.
- Links are a little stronger in every built-in theme (Solarized Dark links were at the
  minimum readable contrast).
- Switches show a check mark in the knob when on, so on and off no longer differ only by
  colour; the Solarized Light off switch has a darker track.
