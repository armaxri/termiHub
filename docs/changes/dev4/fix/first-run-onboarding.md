### Added

- First-run onboarding for the Connections panel: a brand-new user with no saved
  connections now sees a "No connections yet" card with a primary
  **New Connection** call-to-action instead of a blank pane (UX-001). The card
  also signposts the experimental feature areas (SSH Tunnels, Services, Network
  Tools, Workflows) with a link that opens Settings ▸ General, shown only while
  those features are still gated off (UX-002/UX-004). The card disappears as soon
  as any connection or folder exists.
