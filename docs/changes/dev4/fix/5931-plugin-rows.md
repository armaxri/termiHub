### Changed

- The plugin row's status dot says what it means when you hover it: Enabled,
  Disabled or Error. Its type icon names the plugin's type, and a protocol
  parser now shows a binary icon instead of the sliders, which looked like a
  settings button. The status bar's plugin item reads "1 plugin" or
  "3 plugins" instead of "1 · 1"; hovering it shows how many are enabled and
  that a click opens the plugin list (#5931).
