### Changed

- **Back up** now asks for one thing at a time. First choose what to back up, then set
  the backup passphrase ("Everything in this file is locked with the backup
  passphrase."), and only when your saved credentials are included, enter your master
  password in a last step that says why it is needed. The separate "Encrypt the whole
  backup" switch is gone: "Save without a passphrase" is offered on the passphrase step
  while nothing that must stay locked is included. The list of what to back up no
  longer scrolls inside the dialog, and kinds with nothing saved show as one line
  ("3 other kinds have nothing saved yet."). The settings button reads "Back up…" with
  a one-line description (#5847).
