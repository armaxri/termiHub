### Changed

- Both command-mark settings now live together under Settings ▸ Terminal ▸
  Command marks: "Show command marks" (formerly "Command status marks") and,
  nested under it, "Add shell hook to new sessions automatically" (formerly
  "Command marks by default" under General). Searching for the old names still
  finds them (#5633).
- Settings ▸ Schedules no longer repeats its title as an all-caps "SCHEDULES"
  header and offers a "New schedule" button, also in its empty state. The
  Workflows sidebar's empty schedules list has the same button (#5633).

### Fixed

- Opening a Settings category under Advanced (such as Schedules or Import &
  migration) scrolls the category list so the highlighted item is in view
  (#5633).
