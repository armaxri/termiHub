### Added

- **MobaXterm import can bring over the global colours, font and cursor**
  (#4880): the import dialog offers two opt-ins, both off by default. One
  creates a new custom theme "MobaXterm" from MobaXterm's terminal colours and
  selects it; existing themes are never replaced. The other applies
  MobaXterm's global terminal font, font size and cursor style, shown as
  before → after first. Without the opt-ins nothing changes.
