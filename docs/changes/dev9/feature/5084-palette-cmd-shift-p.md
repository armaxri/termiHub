### Added

- On macOS, **Cmd+Shift+P** now also opens the command palette, alongside
  **Cmd+P** (the VS Code habit). It works with a terminal focused too, is listed
  next to Cmd+P in the shortcuts overlay, Settings → Keyboard Shortcuts and the
  cheat sheet, and is dropped when you rebind or unbind the command palette
  (reset restores it) (#5084).
