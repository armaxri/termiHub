### Added

- While broadcasting, the command palette offers **Run Workflow on Broadcast Group**. Pick a
  workflow and it runs on every connected terminal in the broadcast group at the same time
  (up to 8 at once), with the same progress toast and per-terminal run history as **Run on…**.
  The entry is greyed out when no terminal in the group is connected. Press Backspace in the
  empty workflow list to go back to the commands.
