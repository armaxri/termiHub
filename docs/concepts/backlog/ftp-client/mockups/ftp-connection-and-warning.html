Insecure connection warning (on connect, plain FTP)

Shown before the control connection opens when TLS Mode is None. The user can suppress it per connection D or back out.
Insecure Connection

Plain FTP transmits your username, password, and all data in cleartext. Anyone on the network path can intercept your credentials and files.

Consider using FTPS (FTP over TLS) if the server supports it.

Don't warn again for this connection D
