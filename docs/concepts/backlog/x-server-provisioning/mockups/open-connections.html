"X Servers" section among the other connection groups

The managed (or adopted) X server appears as a new X Servers section in the Open Connections modal A, alongside the existing groups. Each row has a Stop control B; the section header carries a count and a Kill all action C — matching how every other section in this panel behaves.

  • A New X Servers section in OpenConnectionsModal.tsx, following the existing Section pattern (title + count + kill-all).
  • B Per-server Stop (lucide Power) terminates the managed vcxsrv.exe.
  • C Kill all stops every managed server — consistent with the panel being the single place to kill any connection.
  • An adopted external server shows as External X server · display :0 with no Stop control (termiHub did not start it, so it does not stop it).
