2 · First-run flow (Windows) — consent → progress → running

Shown the first time an X11-forwarding connection is opened with no reachable X server. Nothing is downloaded before consent C.

Step 1 — consent prompt

Set up X server
Remote GUI apps need a local X server to open as native windows. termiHub can download and set up VcXsrv (~7 MB, one time).

Step 2 — provisioning

Setting up X server
✓ Download VcXsrv
✓ Verify checksum
Extract & start 62%

Step 3 — running

X server running
VcXsrv on display :0 managed
Remote GUI apps now open as native windows. Manage it any time from Open Connections → X Servers.
  • C No network request happens until the user picks Download & Enable. Progress is driven by backend events (download / verifying / status).
  • On subsequent runs (VcXsrv already cached) Steps 1–2 are skipped — the server just starts.

3 · macOS variant — guided XQuartz install (cannot bundle)

macOS cannot embed an X server, so the prompt offers a guided, consent-based install of XQuartz instead of an in-app download.
