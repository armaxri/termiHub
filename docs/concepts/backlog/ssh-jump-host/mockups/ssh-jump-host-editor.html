SSH Jump Host — Connection Editor Section

Layout-altitude mockup · backlog/ssh-jump-host/mockups/ssh-jump-host-editor.html

The Connection Editor opens as a tab in the main area. The Jump Host category is a flat settings-panel__category (the editor has no collapsible groups), after the connection/authentication fields and before the SSH Agent category. Four states below: disabled, saved-connection mode, inline mode, and multi-hop with a connection-path summary + validation error.

1 · Jump Host section disabled (default)

Full app shell. The editor tab is active; the Jump Host category A shows only its title and the "Connect through a jump host" checkbox (unchecked) — the body stays hidden until it is enabled.

2 · Enabled — saved connection reference

Checkbox enabled B reveals the body. Source segmented control C is set to "Saved connection"; the Connection dropdown D lists SSH-type saved connections by full path.

  • D Connection dropdown — SSH-type saved connections only, shown as folder / sub / name (the edited connection excluded).
