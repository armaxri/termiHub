Remote Agents sidebar — per-agent version chip + update-state badge

The Remote Agents view lists every deployed agent. Each row reuses connection-tree__item with a state-dot for liveness, a monospace version chip A, and an update-state badge B whose icon + colour encode the version comparison. A row mid-update shows a spinning badge E plus an inline progress bar F.

Update-state badge — full state space

Each agent row resolves to exactly one of these states. Colour is carried entirely by theme vars so the badges stay consistent with the rest of the app. C down-arrow = newer release exists; D red ✗ = major mismatch / too old to talk to this desktop.
