1 · Login screen (standalone browser page)

Shown before the main UI when the agent requires authentication. This is a standalone browser page, not the termiHub desktop chrome — a centered card built from the theme variables. The primary token field A is the default; a username/password fallback B sits below the "or" divider.

  • B Username + password fallback — used when the agent is in password auth mode.

2 · Connection bar (in the web client, above the terminal)

Once authenticated the web client shows a thin connection bar across the top (it replaces the OS title bar). It carries the health dot C, the agent host D, and a disconnect button E. Below it is the familiar termiHub terminal area.

  • C Health dot — green / yellow / red, mirroring the state-dot colours (good / degraded / down).
  • D Agent host (Server icon) + live latency.
  • E Disconnect (LogOut) — closes the WS and returns to the login screen.
