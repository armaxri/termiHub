Web access · listening
2 clients
  • A Master toggle — listener does not bind until on.
  • B Listen address / port — 0.0.0.0 exposes the agent on the LAN (explicit opt-in); default is 127.0.0.1:7681.
  • C TLS mode (Lock icon) — Self-signed / Custom cert / Disable (LAN only).
  • D Auth mode (Key icon) — Token or Username + Password; the masked token row offers Regenerate / Copy.
  • E Access URL — resolved https://<ip>:<port> with Copy / Show QR.
  • F QR code (QrCode) — scan to open the login screen on a mobile device.

2 · Control states

Key control variants. Disabled G = master toggle off, listener stopped, fields greyed and URL/QR hidden. TLS disabled H = the not-recommended LAN-only mode shows a warning. Username + Password auth mode I swaps the token row for credential fields.
