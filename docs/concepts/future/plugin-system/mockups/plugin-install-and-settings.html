1 · Install from file — permission prompt

After picking a .termihub-plugin file, the parsed manifest A and a Requested Permissions list B are shown on the shared menu overlay. The footer offers Cancel and Install & Enable C.

  • B Requested permissions — each with a ShieldAlert icon (amber) and plain-language explanation.
  • C Footer — Cancel aborts; Install & Enable extracts, grants permissions, and enables.
