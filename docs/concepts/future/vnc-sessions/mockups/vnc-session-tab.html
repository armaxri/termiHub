1 · Connected — canvas, hover toolbar, status segment

A VNC connection opens as a vnc tab in the normal tab/panel system. The canvas A fills the panel content where a terminal would sit (plain placeholder surface, not a screenshot). The floating hover toolbar B auto-shows near the top edge. The status bar carries a VNC segment C.

2 · Connecting overlay

While the proxy and optional SSH tunnel come up and the RFB handshake runs, a centered overlay D covers a dark canvas. The tab dot is amber (connecting); the status segment reads "connecting".

3 · Reconnect overlay (connection lost)

On an unexpected drop, noVNC reports the disconnect and the canvas shows a "Connection lost" overlay E with an auto-reconnect countdown and a manual Reconnect button. The tab dot turns red.

  • E Reconnect overlay — countdown + manual refresh-cw Reconnect button.

In view-only mode the canvas still renders but input is suppressed. The toolbar shows a persistent View Only badge F (lucide eye-off); no Ctrl+Alt+Del button is offered.
