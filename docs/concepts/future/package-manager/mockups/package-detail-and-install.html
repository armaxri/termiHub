3 · Install confirm dialog — dependency review & tool install

Installing a package that pulls in dependencies opens a confirm dialog on the .menu overlay. It lists the resolved install order C (primary + auto-installed deps), notes external requirements D, and shows total download / install size E. The tool-install variant adds the target tools directory F and platform/arch.
