# scripts/internal

Internal helper scripts used by other scripts or tooling. These are **not** intended for direct use by developers.

| File                              | Used by                                                                                        | Purpose                                                                                                                                                                                                                 |
| --------------------------------- | ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `autoformat.sh`                   | `.claude/settings.json` PostToolUse hook                                                       | Auto-format a single edited file (Prettier / rustfmt) and refresh the `data-testid` catalog when a source `.tsx` changes                                                                                                |
| `check-script-parity.sh`          | `Shell Script Quality` CI job                                                                  | Fail if a `scripts/**/*.sh` lacks its `.cmd` twin (or vice-versa), minus a documented single-platform allowlist (TOOL-012), or if a pair's halves accept different flags (#3340)                                        |
| `check-script-headless.sh`        | `Shell Script Quality` CI job                                                                  | Execute each script's `--help` path and assert exit 0 — catches runtime `set -u`/expansion faults static checks miss (TOOL-012)                                                                                         |
| `ci-rust-tests.sh`                | `code-quality.yml` / `agent.yml` tests                                                         | Run the Rust tests in two phases: bulk at default parallelism, then contention-sensitive suites with capped `--test-threads`; `list` verifies the partition (CI-013)                                                    |
| `build-system-test-app.sh`        | `system-integration.yml` / `test-system-py.sh`                                                 | The one build recipe for the app the Python bridge harness drives (`--features test-bridge` + `VITE_TEST_BRIDGE=1`, mock-remote-desktop); lives with the graded code so a workflow copy cannot drift (#3664)            |
| `native-sshd-fixture.sh` / `.ps1` | `run-native-sshd-suites.sh` / `system-integration.yml` (Windows) / harness `NativeSshdFixture` | Native loopback sshd fixture (`up`/`stop`/`start`/`env`/`down`): unprivileged `/usr/sbin/sshd` on macOS/Linux, a Win32-OpenSSH service + local test user on Windows; exports `TERMIHUB_NATIVE_SSHD_*` (CI-020, TIN-007) |
| `run-native-sshd-suites.sh`       | `integration-fixtures.yml` `native-sshd` job                                                   | Fixture up, `core/tests/ssh_native.rs` under `TERMIHUB_NATIVE_SSHD=1`, sshd log on failure, teardown (CI-020, TIN-007)                                                                                                  |
| `lcov-merge.mjs`                  | `coverage.sh` / `coverage.cmd`                                                                 | Merge the nightly integration lcov into the unified unit report per source file (unit report owns the denominator, stale files skipped) and write the integration gap report (TOOL-005, #3656)                          |
| `fetch-integration-coverage.mjs`  | `coverage.yml`                                                                                 | Download the newest instrumented `integration-fixtures.yml` run's `integration-coverage` artifact for a branch and list files changed since its commit (TOOL-005, #3656)                                                |
| `coverage-ratchet.mjs`            | `coverage.sh` / `coverage.cmd`                                                                 | Fail-on-decrease coverage gate: grade per-component unit line coverage against `scripts/coverage-baseline.json`; `--update` raises the baseline (#3740)                                                                 |
| `llvm-cov-report.mjs`             | `coverage.sh` / `coverage.cmd`                                                                 | Run `cargo llvm-cov report --lcov`, dropping a truncated `.profraw` and retrying so a corrupt profile cannot red the gate (#3740)                                                                                       |
| `release-integration-gate.mjs`    | `release.yml` (Verify Integration Lanes)                                                       | Refuse a release unless the newest Release Candidate: Full Integration run and Code Quality push run on the tag's exact commit are green; prints the fix-up commands otherwise (#3652)                                  |
| `agent-update-signing.sh`         | `release.yml` / `dev-build.yml`                                                                | Sign agent binaries (`<bin>.sig`, Ed25519 over a domain-separated SHA-256), verify them, and `check-key` fail on the placeholder key (AGT-005, #3213)                                                                   |
| `setup-agent-signing-key.sh`      | maintainer (one-time)                                                                          | Generate the agent update signing keypair, write the public key file, store the private key only as the `AGENT_UPDATE_SIGNING_KEY` secret; `--dry-run` for a no-upload trial                                            |
| `check-branch-protection.mjs`     | `branch-protection.yml` (weekly) / `apply-branch-protection.sh`                                | Compare live `main`/`develop` protection with `.github/branch-protection.json` and report drift; `--payload <branch>` prints the REST PUT body (CI-017, #3675)                                                          |
| `apply-branch-protection.sh`      | maintainer (admin, manual)                                                                     | Apply `.github/branch-protection.json` to a branch via `gh api -X PUT`; dry run by default, `--apply` writes (CI-017, #3675)                                                                                            |
| `pr-gate.mjs`                     | `code-quality.yml` (PR Gate)                                                                   | Evaluate `toJSON(needs)` for the always-reporting `PR Gate` aggregate: fail if a needed job failed or was cancelled, skipped passes; its test keeps the gate's `needs:` in sync with the workflow (#3678)               |
| `regen-testid-catalog.mjs`        | `autoformat.sh`                                                                                | Regenerate `tests/system/testid-catalog.md` when the edited file is a source `.ts`/`.tsx` containing a `data-testid` (#1084)                                                                                            |
| `third-party-notices.mjs`         | `pnpm notices:generate` / `notices:check`, `release.yml`, `security-audit.yml`                 | Generate `THIRD_PARTY_NOTICES.txt` (full license texts of all shipped Rust crates + npm prod deps via pinned cargo-about); `check` gates about.toml/deny.toml drift and npm licenses (PKG-009)                          |
| `kill-port.cjs`                   | `dev.sh` / `dev.cmd`                                                                           | Kill any process occupying the Vite dev server port                                                                                                                                                                     |
| `dev-local.mjs`                   | `vite.config.ts` / `tauri.mjs`                                                                 | Resolve this checkout's `dev_port` from `dev.local.json` — Node half of the resolver (#1588)                                                                                                                            |
| `tauri.mjs`                       | `pnpm tauri`                                                                                   | Merge this checkout's `dev_port` into `tauri dev`'s `build.devUrl`; every other subcommand passes through (#1588)                                                                                                       |
| `package-vcxsrv.ps1`              | release process (operator, Windows)                                                            | Build the pinned minimal VcXsrv `.zip` for SSH X11 forwarding from an installed VcXsrv, print/patch its SHA-256 (#1076)                                                                                                 |
| `package-vcxsrv.sh`               | `package-vcxsrv.ps1`                                                                           | Git-Bash wrapper that forwards long flags to `package-vcxsrv.ps1`                                                                                                                                                       |
